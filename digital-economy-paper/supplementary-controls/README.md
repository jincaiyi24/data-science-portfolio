# 新增控制变量与模型复核

本目录记录论文后续的控制变量增强实验。新增变量包括无形资产比率、固定资产比率、经营现金流比率、资本开支强度和研发强度，数据来自 OpenDART 或既有冻结面板。

## 主要结论

- 基准模型中 BMI 披露系数为 `0.030243`，p<`0.001`。
- 加入四项高覆盖控制变量后，系数为 `0.029818`，p<`0.001`，样本量为 `12,658`。
- OpenDART 研发强度覆盖率约 `4.0%`，全扩展模型只剩 `480` 个公司年度，因此只作为敏感性分析。
- Python 与 Stata 对核心模型的系数和样本量一致，标准误只有很小的实现差异。

## 文件

- `论文2_新增控制变量与模型增强结果.xlsx`：汇总工作簿。
- `论文2_新增控制变量与模型增强报告.pdf` / `.docx`：结果说明。
- `src/paper2_extended_controls_pipeline.py`：数据取得、变量构造和模型流程。
- `stata/paper2_stata_validation.do`：Stata 复核代码。
- `stata/paper2_stata_validation_sample.dta`：只含研究变量的验证样本，不含公司地址和年报全文。
- `results/`：完整回归、核心系数、FDR 与 Python/Stata 对照结果。

运行 OpenDART 抓取前，将 API 密钥放入环境变量 `DART_API_KEY`。代码不会从仓库读取或保存密钥。

# 商业模式导向型数字披露与后续资产使用效率

本项目研究韩国 KOSPI 与 KOSDAQ 非金融上市公司的年报数字化披露，尝试回答一个具体问题：描述平台、线上渠道、数字服务和收入安排的披露，与一般系统升级、基础设施和内部自动化披露，是否具有不同的后续经营含义。

- [`可编辑稿 DOCX`](paper/商业模式导向型数字披露与后续资产使用效率_可编辑稿.docx)（较早的可编辑底稿）

`paper/` 中的版本晚于 `reports/` 里的阶段性中韩文报告；阅读和引用应以证据修订版 PDF 为准。

## 数据与方法

- 基础面板：2015-2025 年，22,654 个公司年度，2,402 家公司。
- 主回归：2016-2023 年，13,980 个公司年度，2,054 家公司。
- 文本来源：DART/OpenDART 韩文年度报告。
- 识别方法：句子级规则区分商业模式导向披露（BMI）与一般技术导向披露（NonBMI）。
- 计量方法：公司固定效应、年份固定效应、公司聚类标准误，并进行共同样本、替代口径、时间边界、VIF、样本留存和样本外预测检查。

主规格中，商业模式导向型数字披露的系数为 `0.0302`（SE=`0.0069`, p<`0.001`）。该结果表示选择后的平均条件关联，不等于因果效应；四分位距变化对应的条件差异约为资产周转率均值的 `1.44%`，样本外预测改善约 `0.07%`，实际预测价值很弱。

## 为什么没有只报告显著结果

论文同时保留了盈利、资本市场反应、样本外预测等非支持性结果，并明确披露曾比较大量候选模型、文本重建存在差异、缺少第二名独立编码者、动态固定效应偏误和时变遗漏因素仍可能存在。这些限制决定了结论只能是相关性证据。

## 数据公开边界

仓库没有上传原始年报全文、49 MB 冻结面板、公司地址明细、第三方市场数据或 OpenDART 密钥。`methodology/05_变量字典.csv` 记录变量口径，代码从环境变量 `DART_API_KEY` 读取接口密钥。复现完整结果还需要根据数据来源条款重新取得底层数据，并配置脚本中的输入目录。

## 补充控制变量

`supplementary-controls/` 检查了无形资产、固定资产、经营现金流、资本开支和研发强度等额外控制。高覆盖控制变量没有推翻主结果；OpenDART 研发强度覆盖率只有约 `4.0%`，因此只作为敏感性分析，不能据此否定主样本结果。

## 解释边界

年报披露不等于项目已经实施，更不等于数字化导致经营效率变化。本项目的贡献是把不同内容类型的披露分开测量，并用可追溯的实证检查说明证据支持到哪里、不能支持到哪里。

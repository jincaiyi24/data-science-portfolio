# 이력서 프로젝트 요약

- 66.9만 건의 고객 데이터를 기반으로 EV 구매 성향 분석 파이프라인을 구축하고 데이터 품질 점검, 고객 세분화, Power BI용 데이터를 완성했습니다.
- 5-fold Stratified CV로 6개 모델을 비교하고 feature ablation, multi-seed audit, OOF blending을 적용해 최종 ROC-AUC 0.9457를 기록했습니다. Kaggle Public AUC 0.94589, 458/1509위입니다.
- SHAP과 규칙 기반 세그먼트를 결합해 주요 구매 연관 요인을 해석하고 타깃 마케팅, 충전 지원, 보조금 커뮤니케이션 방안을 제안했습니다.
- SQLAlchemy, PyMySQL, MySQL 8로 4개 테이블 분석 파이프라인을 구축해 95.5만 명의 특성, 실제 OOF/Test 예측, 비즈니스 세그먼트를 적재했으며 13개 DB 검증, 13개 SQL 결과, 18개 Python-SQL 무차이 대조를 완료했습니다.

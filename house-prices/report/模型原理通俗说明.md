# 最终四个模型，用大白话说明

## 1. Elastic Net：给每个条件估一个“加减价”

可以把房价想成“基础价 + 各项配置的加减价”。面积更大加多少，装修更好加多少，车库更大再加多少，这就是线性模型的基本想法。

房价数据经过独热编码后会产生几百个变量，其中不少变量表达的意思相近。普通线性回归很容易让这些变量互相抢功劳，系数变得不稳定。Elastic Net 会对过大的系数收取惩罚，并把作用很弱的变量压到接近 0，因此更适合小样本、高维度的数据。

它的优点是稳定、速度快、容易解释；局限是很难单独表达复杂的门槛和交互关系。

## 2. Gradient Boosting：让后一棵树专门改前面的错误

第一棵树先给出一个粗略房价。第二棵树不从头预测，而是学习第一棵树在哪些房子上估高了、哪些房子上估低了。后面的树继续修正前面剩下的错误，很多棵小树相加后形成最终结果。

例如，模型先发现“面积越大通常越贵”，随后又发现“同样的面积，质量评分 8 分以上的房子涨价更明显”，再下一棵树继续处理“老房翻新后价格不同”的情况。这种逐步纠错很适合房价中的非线性关系。

本项目使用 Huber 损失和较浅的树，减少个别异常成交价对整体模型的影响。

## 3. XGBoost：更严格、更高效的提升树

XGBoost 和 Gradient Boosting 的核心都是逐步纠错，但 XGBoost 对树的复杂度、叶节点权重和随机抽样控制得更细，还能高效处理稀疏特征。

可以把 Gradient Boosting 理解为一支不断复盘的团队，XGBoost 则在复盘之外增加了预算纪律：每次分裂是否真的值得、模型是否过于复杂、是否需要随机少看一部分样本和特征，都有明确约束。

它的优点是能学习复杂交互，性能通常较强；局限是容易与其他树模型犯相似的错误，因此不能仅凭单模分数决定融合价值。

## 4. RBF-SVR：让相似的房子得到相近的估价

SVR 的思路不是切很多规则，而是在高维空间里找一条尽量平滑的预测面。RBF 核会根据两套房子在各种特征上的距离判断它们有多相似：越相似，彼此对预测的影响越大。

例如，两套房的面积、质量、房龄、车库和社区都接近，那么即使没有一条完全相同的树规则，SVR 仍会让它们的估价保持接近。

参数 `C` 控制模型多认真追逐训练误差，`epsilon` 表示多大的误差可以暂时不管，`gamma` 控制“相似”影响的范围。本项目选择了较小的 `gamma`，让预测面更平滑，避免只记住局部样本。

## 5. 为什么要融合

四个模型看问题的方式不同：Elastic Net 擅长稳定的整体加减价，两个提升树擅长门槛和交互，SVR 擅长平滑的相似性。融合不是投票选冠军，而是让它们共同给出估价。

权重来自训练集之外的 OOF 预测。每套训练房屋都由“没有见过它”的模型预测，再根据这些预测计算非负权重。权重总和固定为 1，并增加 L2 惩罚，防止某一次验证切分把权重全部推给单一模型。

## 6. 最后的轻度校准

残差分析发现低价房仍容易被高估，高价房仍容易被低估，即预测范围被向平均值轻微压缩。最终仅使用一条线性校准式把预测范围拉开约 1.6%。校准幅度被限制在合理范围内，不允许为了本地分数做激进变换。

这一步改善了本地误差，但并没有消除未知测试集差距，所以报告仍把尾部预测列为主要局限。
